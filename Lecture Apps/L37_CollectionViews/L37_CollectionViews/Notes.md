# Collection Views
- Uses layouts for cells

## Orthogonal Scrolling
- A collection view can scroll in one direction only, either vertically or horizontally.

## Anatomy of a Collection View
- Cell dequeuing and resuse
- IndexPath-Based
- UIKit provides UICollectionViewController

## Compositional Layout
- Item:-
    - Contained inside a Group
- Group:-
    - Contained inside a Section
- Section
